# YOWLMAFFIA GitHub Releases

Gebruik deze map als bron voor een GitHub Release.

## Bestanden

- `YOWLMAFFIA.exe`
- `YOWLMAFFIA.exe.blockmap`

## Hoe publiceren

1. Maak een GitHub tag aan, bijvoorbeeld `v1.0.1`.
2. Laat de GitHub Actions workflow de release bouwen.
3. Voeg de bestanden uit deze map toe aan de GitHub Release.
4. Kopieer de directe downloadlink van `YOWLMAFFIA.exe`.
5. Plak die link in de update-instellingen van de app.

## Voor de app

- De teamleden installeren alleen de app.
- Updates worden daarna via de app en de GitHub Release-link opgehaald.
- Geen Node.js nodig op toestellen van het team.
